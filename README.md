# 🖥️ System Metrics Monitor

Простой инструмент на Python для быстрого получения текущих метрик операционной системы (процессор, оперативная память, постоянная память) с использованием библиотеки `psutil`.

## 🛠️ Функционал

Модуль предоставляет следующие функции для мониторинга:
* **`get_cpu_usage()`** — Возвращает текущую общую загрузку процессора в процентах (с интервалом замера в 1 секунду).
* **`get_memory_usage()`** — Возвращает процент используемой оперативной памяти (RAM).
* **`get_disk_usage()`** — Возвращает процент занятого пространства на основном жестком диске (корневой раздел `/`).
* **`get_cpu_all_cores()`** — Вспомогательный метод для проверки наличия логических и физических ядер в системе.

## 📦 Требования и установка

Для работы скрипта необходим установленный Python версии 3.7+ и библиотека `psutil`.

1. Клонируйте репозиторий:
```bash
git clone https://github.com
```

2. Установите зависимости:
```bash
pip install psutil
```

## 🚀 Пример использования

Вы можете импортировать эти функции в своего Telegram или Discord бота:

```python
from metrics import get_cpu_usage, get_memory_usage

print(f"Текущая загрузка CPU: {get_cpu_usage()}%")
print(f"Использование памяти: {get_memory_usage()}%")
```
